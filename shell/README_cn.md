概述
----
Shell 是产品的命令行界面。它使用户能够以安全的方式
读取和更改数据库中的各种数据。提供的命令接近 100 个，
所以开始时可能会很多。基本思想是您始终可以输入"help"
获得帮助 - 在系统的任何地方。帮助是上下文敏感的。

Shell 的主要目的是：

* 提供系统的接口（作为 Web 界面的替代方案）
* 提供脚本功能
* 将旧版本迁移到新版本
* 导出/导入数据库数据
* 清理和大规模作业
* 相当先进的 TR-069 设备测试系统接口
* 在受限模式下运行 - 可以设置为直接在 SSH 连接上打开

Shell 提供管道和变量、if/else、while/done 以及其他一些
构造来真正制作复杂的脚本。脚本还可以调用其他脚本。

总之，此脚本语言是类似 bash 的脚本语言的相当简单的子集。
它从未打算如此高级，但由于各种原因，它逐渐变成了这样。

scripts 文件夹保存了过去几年制作的许多脚本，
您可能会在那里找到技巧和窍门。docs 文件夹也包含
整个项目的用户手册。
